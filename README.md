# Desafio 5 — Testes E2E com Cypress

Projeto de testes automatizados da loja de demonstração SauceDemo, desenvolvido com Cypress.

## Tecnologias
- Node.js
- Cypress

## Executar o projeto

Instalar as dependências:

`npm install`

Abrir o Cypress:

`npx cypress open`

Executar os testes em modo headless:

`npx cypress run`

## Casos de teste

Os cinco cenários estão documentados em `docs/casos-de-teste.md`.

## Evidências

Os resultados da execução devem ser registrados na pasta `evidencias/`.
